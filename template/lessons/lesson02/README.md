# Lesson 02 – Lists and loops

Write these functions in `solution.py`:

1. `total(numbers)` – return the sum of a list of numbers (without using `sum()`).
2. `only_positive(numbers)` – return a new list with only the numbers greater than 0.
3. `count_vowels(text)` – return how many vowels (`a e i o u`, any case) are in `text`.

Check your work: `cd lessons/lesson02 && pytest -v`
